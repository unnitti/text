# 클립보드 가공

iPhone 사진의 Live Text가 인식한 텍스트에서 상품코드·날짜·지번을 추출해 복사하기 쉽게 정리하는 웹앱입니다.

**[앱 실행하기](https://unnitti.github.io/text/)**

## 사용 방법

기본 흐름은 **사진 → Live Text로 텍스트 복사 → 앱에서 클립보드 불러오기 → 결과 확인 → 결과 복사**입니다. 단축어를 이용해 텍스트를 전달할 수도 있습니다. 클립보드 불러오기 대신 입력창에 직접 붙여넣어도 자동 처리됩니다.

## 처리 규칙

- **상품코드:** 입력 텍스트 전체에서 `영문자 1개 + 영문자/숫자 8개 + 공백 또는 줄바꿈 + 영문자/숫자 3개` 패턴을 찾습니다. 대소문자는 구분하지 않고, 결과는 대문자로 바꾸어 공백 없이 표시합니다. 예: `abc123456 xyz` → `ABC123456XYZ`.
- **날짜:** `소비기한 YYYY-MM-DD`는 `소비 YY.MM.DD /`, `제조일자 YYYY-MM-DD`는 `제조 YY.MM.DD /` 형식으로 표시합니다. `판매 가능`이 포함된 줄과 그 다음 줄은 날짜 검색에서 제외합니다.
- **지번:** `11-`로 시작하는 영문자·숫자 조각이 하이픈으로 이어진 패턴을 찾습니다. 앞의 `11-`을 빼고 `지번 XXXXX`로 표시하며, 중복은 한 번만 출력합니다.
- 결과는 상품코드, 날짜, 지번 순서입니다. 같은 종류의 결과는 원문에서 발견된 순서를 따릅니다.

## 오프라인 사용 및 업데이트

- 처음에는 인터넷에 연결된 상태에서 앱을 열어 주세요. 앱 파일은 브라우저에 캐시되므로, 이후에는 인터넷 연결이 불안정하거나 끊긴 상황에서도 사용할 수 있습니다.
- 앱을 업데이트할 때는 인터넷에 연결한 상태에서 앱을 다시 열어 주세요. 새 버전의 파일을 내려받아 적용합니다.
- 앱 파일을 변경해 배포할 때는 `sw.js`의 캐시 버전도 함께 올려야 합니다. 버전이 바뀌면 새 파일을 캐시에 준비한 뒤 이전 캐시를 교체합니다.
- 브라우저의 웹사이트 데이터나 캐시를 삭제한 경우에는 인터넷에 연결해 앱을 다시 열어야 합니다.

## 지원 환경 및 한계

- iPhone Safari의 홈 화면에 추가한 웹앱을 기준으로 확인했습니다. Safari 탭, Android 및 다른 브라우저에서의 동작은 별도 확인이 필요합니다.
- 사진 OCR은 하지 않습니다. 사진 문자는 iPhone Live Text가 인식하며, 인식 오류·누락은 추출 결과에 영향을 줍니다. 중요한 정보는 원문과 대조하세요.
- 앱은 정해진 업무 자료 패턴만 처리하며, 임의의 문맥을 이해하지 않습니다. 날짜는 `YYYY-MM-DD` 형식만 대상으로 합니다.
- 별도 설치 없이 브라우저에서 사용할 수 있으며, 홈 화면에 추가해 앱처럼 실행할 수 있습니다.

## 유지보수 메모

- 정상 사용 중인 추출 규칙은 필요한 경우에만 변경하고, 기존에 잘 처리되던 입력도 함께 확인합니다.
- 단축어의 전달 방식을 수정하면 실제 iPhone Safari에서 점검합니다.
- Live Text가 담당하는 OCR과 웹앱이 담당하는 텍스트 가공을 구분해 유지합니다.
- 기능을 수정할 때는 온라인 실행, 오프라인 재실행, 주요 추출 및 복사 기능을 함께 점검합니다.
